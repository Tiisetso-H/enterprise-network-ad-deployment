
# Enterprise Network Infrastructure and Active Directory Deployment

This repository showcases the comprehensive design and implementation of a converged network and systems infrastructure for a two-site enterprise operating across Johannesburg and Pretoria. 

The project integrates four major IT disciplines into a unified architecture, beginning with structured Variable Length Subnet Masking IP address planning and a three-tier hierarchical switch topology featuring Spanning Tree Protocol for loop prevention. A multi-site Windows Server Active Directory domain was deployed with a department-aligned Organisational Unit hierarchy, bulk user provisioning via automated scripts, and granular security group management. 

Centralized file and print services were established with strictly scoped NTFS and share permissions, while domain-wide security baselines were enforced through Group Policy Objects. The architecture concludes with a forward-looking cloud migration strategy integrating the on-premises environment with Microsoft Azure and Microsoft 365, demonstrating enterprise-grade systems administration and network engineering expertise.
